# Bright Path Academy – Student Records Portal

## Put it on GitHub Pages
1. Create a new GitHub repository and upload everything in this folder (index.html, manifest.json, sw.js, the icons folder).
2. Repository **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`. Save.
3. After a minute your site is live at `https://YOUR-NAME.github.io/REPO-NAME/`.

## Turn it into an app (PWABuilder)
1. Go to pwabuilder.com and paste your GitHub Pages link.
2. Fix nothing – the manifest, service worker and icons are already included. Click **Package for stores** and pick Android / iOS / Windows.

## Before first use
Open **Subjects** and add the subjects for JSS 1–3 and for SS Art, Commercial and Science. New students get those subjects automatically.

## Saving
Changes save in the browser. Use **Settings → Export data / Import data** to back up or move data between devices.
For shared cloud saving later, fill in `CFG` near the top of the script in index.html with your Firebase keys.
